# 개인정보 처리방침 — 가계력

**시행일: 2026년 11월 4일**

가계력(Gagyeryeok)은 쓴 돈을 달력에 기록하는 가계부 앱입니다.
이 앱은 **어떤 개인정보도 수집하지 않고, 어디로도 전송하지 않습니다.**

## 수집하는 정보

없습니다.

이 앱에는 서버가 없습니다. 회원가입도, 로그인도, 계정도 없습니다.
분석 도구나 광고 SDK를 넣지 않았고, 제3자 서비스와 통신하지 않습니다.
은행이나 카드사 계정에 연결하지 않습니다.

## 기기에 저장되는 것

앱이 동작하려면 아래 정보를 **사용자의 기기 안에만** 저장합니다.
개발자를 포함해 누구도 이 정보에 접근할 수 없습니다.

| 저장 항목 | 내용 |
|---|---|
| 거래 기록 | 지출·수입·이체의 금액, 날짜, 계좌, 카테고리, 메모 |
| 계좌 | 사용자가 입력한 이름, 종류, 용도, 초기 잔액 |
| 카테고리 | 이름, 종류, 아이콘 |
| 자동이체 | 이름, 금액, 계좌, 카테고리, 주기, 출금일, 시작일과 종료일 |

계좌번호나 카드번호를 입력받지 않습니다. 앱을 삭제하면 이 정보는 기기에서 함께 삭제됩니다.

## 백업

**설정 → 백업 · 복원 → 백업 파일 만들기** 를 누르면 위 정보가 파일 하나로 만들어집니다.
이 파일은 사용자가 직접 고른 곳(파일 앱, AirDrop 등)으로만 보내지며, 앱이 스스로 어딘가로
전송하지 않습니다. **파일은 암호화되지 않으므로** 믿을 수 있는 곳에 보관해 주세요.

복원할 때는 복원 직전의 데이터를 기기 안에 자동으로 백업하며, 최근 3개까지 보관합니다.

## 기기 권한

이 앱은 위치, 사진, 연락처, 알림 같은 기기 권한을 요청하지 않습니다.
