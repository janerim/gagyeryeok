# 가계력 할 일

다른 기기나 세션에서 이어서 작업할 때 보는 문서다. 결정된 내용은 여기 적고, 끝난 항목은 체크한다.
기능 범위의 큰 틀은 [gagyeryeok-plan.md](../gagyeryeok-plan.md), 스토어 문구는 [appstore-metadata.md](appstore-metadata.md).

## 현재 상태 (2026-11-05)

- TestFlight 에 **0.1.0 빌드 6** 까지 올라가 있다. 한 달쯤 실사용 테스트 뒤 App Store 출시 예정.
- 출시 때 정할 것: 버전 번호(0.1.0 → 1.0.0?), `docs/appstore-metadata.md` 의 "미정" 항목.
- **출시할 때 책력 1.1.1 도 같이 올린다.** 책력(`../chaekryeok`)의 탭바·헤더 아이콘과 보조 글자색을 가계력과 맞춘 버전이고,
  새 기능이 없어서 따로 올리지 않고 가계력 출시에 맞춘다. 할 일과 문구는 책력의 `RELEASE_NOTES.md` "1.1.1" 에 있다.
- 빌드·제출: `eas build --platform ios --profile production --non-interactive --auto-submit`
  (빌드 번호는 자동 증가. 끝나면 App Store Connect → TestFlight 에 5~10분 뒤 나타난다)
- 확인 명령: `npm run typecheck`, `npm test`, `npx expo export --platform ios --output-dir /tmp/x` (번들 깨짐 확인)

## 진행 중: 실사용 피드백 7가지

사용자 요청과 합의한 설계. 묶음 순서대로 하고, 묶음마다 커밋 + TestFlight 빌드.

### 1차 묶음 (작은 것들)

- [x] **내역·통계에 "이번 달" 버튼** — 캘린더의 "오늘" 버튼과 같은 자리(헤더 오른쪽).
- [x] **달 선택 팝업** — 헤더의 `26년 11월` 글자를 누르면 시트: `‹ 2026 ›` + 12개월 격자.
      `MonthNavigator` 에 `onPressLabel` 을 추가해 캘린더·내역·통계 세 탭에 한 번에 적용.
- [x] **내역 필터 초기화** — 유형·계좌·카테고리 중 하나라도 걸려 있으면 필터 줄 끝에 `✕` 버튼, 누르면 전부 해제.
- [x] **거래 입력 화면 압축** (빌드 7)
  - 날짜를 한 줄로: `날짜  ‹ 2026.11.04 (수) ›  오늘` (라벨을 같은 줄에). 날짜 글자를 누르면 달력 시트에서 직접 고른다.
    `DateStepper` 에 달력 시트를 붙이면 자동이체의 시작일도 같이 좋아진다. 달력은 기존 `Calendar` 컴포넌트 재사용.
  - 하단 버튼을 한 줄로: `[삭제] [수정]` (삭제는 좁은 빨간 테두리, 수정은 넓은 초록). 새 거래는 저장만.
    계좌·자동이체 폼도 같은 푸터 컴포넌트(`FormFooter`)로 통일.

### 2차: 홈에 생활비 잔액

- [x] 계좌 폼에 **"홈에 잔액 표시"** 토글 (한 계좌만 켜진다). `account.show_on_home` 컬럼 추가 → 마이그레이션 v2.
      백업/복원은 스키마 버전을 들고 다니므로 추가 작업 없음(`restore` 가 예전 백업에 v2 를 적용한다).
- [x] 캘린더 요약 아래 한 줄 (빌드 8). 이 계좌로 들어올 예정 이체도 더한다 (`domain/homeBalance.ts`):
      `생활비 통장 523,000원 · 예정 자동이체 −120,000 → 쓸 수 있는 403,000 · 25일 남음, 하루 1.6만`
  - 잔액 = `computeBalance` (계좌 탭과 같은 계산)
  - 예정 자동이체 = 이번 달 남은 출금 중 이 계좌가 출금 계좌인 것 (`scheduledByDate` 재사용, 이체 포함)
  - 하루 = 쓸 수 있는 돈 ÷ (이번 달 남은 일수, 오늘 포함)
- 나중에 월 예산 설정(기획서 2차)으로 키울 수 있다.

### 3차: 월 캘린더에 주간 합계

- [x] 달력 오른쪽에 **8번째 열**: 각 주의 **지출 합계만** (`-23.4만`). 요일 헤더에는 `주`. (`Calendar` 의 `renderWeek`, 빌드 9)
      날짜 칸이 53pt → 47pt 정도로 줄어든다. 수입은 넣지 않는다.
- 나중에: 주 합계 칸을 누르면 그 주 내역 시트.

### 4차: 계좌·카테고리 순서를 드래그로

- [x] 계좌 관리·카테고리 관리에 **편집** 버튼 → 편집 모드에서 행 오른쪽 `≡` 손잡이를 끌어 이동 → **완료**. (빌드 9)
      항상 드래그되게 하지 않는 이유: 스크롤하다 실수로 옮기기 쉽다.
- 라이브러리: `react-native-reorderable-list` 0.18 (네이티브 코드 없음 → Expo Go 가능).
  시뮬레이터에서는 렌더링만 확인했고 **실제 드래그는 기기에서 확인 필요**. gesture-handler 3 과
  안 맞으면 `Gesture.Pan` + reanimated 로 직접 구현.
- 기존 ▲▼ 버튼은 뺐다.

### 5차: UI 검토 반영 (빌드 전, 기기 확인 필요)

2026-11-05 에 화면 전체를 검토하고 합의한 것들. 타입 체크·테스트·번들 내보내기까지만 확인했다.

- [x] 새 거래를 열면 그 유형에서 **마지막에 쓴 계좌를 미리 선택**. 실사용해 보고 계속 둘지 정한다.
- [x] **키보드가 올라오면 하단 버튼(삭제·저장)이 키보드 위로** 올라온다 (`hooks/useKeyboardInset`, 폼 4개).
      `automaticallyAdjustKeyboardInsets` 는 뺐고, 가려진 입력은 훅이 보이는 데까지 스크롤한다.
- [x] 보조 글자색 `#888888` → `#6B7280`, 달력 예정 금액 투명도 0.4 → 0.55.
- [x] 통계 막대를 초록(primary)으로.
- [x] 탭바·헤더 버튼을 `@expo/vector-icons`(Ionicons)로. 나머지 문자 기호(≡ ✕ ▾, 시트의 ‹ ›)는 그대로.
      탭바·월 이동 헤더는 책력과 한 벌이라 책력도 같이 바꿨다 (보조 글자색 포함). 한쪽을 바꾸면 다른 쪽도 같이 바꾼다.
- [x] 계좌 탭 맨 위 **전체 합계** (숨김 제외, 카드 포함).
- [x] 내역 **메모 검색** (보고 있는 달 안에서만), 날짜 머리글에 그날 합계.
- [x] **수입형 자동이체** (월급 등). 기획서 4장의 "지출형 / 이체형"에 수입형을 더한 것.
      달력 칸에 예정 수입을 흐린 파랑으로, 홈의 "쓸 수 있는 돈"에는 그 계좌로 들어올 예정 수입도 더한다.
- [x] 카테고리 폼도 `FormFooter`, 자동이체 폼 계좌 칩에 카드 색, 내역 스와이프 취소 시 줄 닫기,
      쓸 수 있는 돈이 마이너스면 빨강, 기호 버튼에 `accessibilityLabel`.
- [x] 좁은 화면(375pt) 대비: 월 이동 간격 16 → 8, 아이콘 버튼 36pt 고정.

- 폼 4개에서 키보드가 올라올 때 하단 버튼 위치, 아래쪽 입력(자동이체 출금일, 계좌 초기 잔액)이 가려지지 않는지

## 작업 방식 메모

- 화면 변경은 실제 기기(Expo Go 또는 TestFlight)에서 본다. 같은 Wi-Fi 가 아니면 Expo Go 는 안 붙는다.

  `defaults write host.exp.Exponent EXDevMenuIsOnboardingFinished -bool true` (안내 시트 끄기) →
  `exp://127.0.0.1:8081/--/<route>` 로 딥링크. 앱 DB 는 `Documents/ExponentExperienceData/@janerim/gagyeryeok/SQLite/gagyeryeok.db`.
