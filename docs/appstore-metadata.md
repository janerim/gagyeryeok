# App Store 등록 문구

App Store Connect 에 그대로 붙여 넣는 텍스트다. 형식과 문장은 집중력·책력 저장소의
`docs/appstore-metadata.md` 와 맞췄다. 스토어에서 직접 고치면 무엇을 왜 바꿨는지 남지
않으니, 고칠 때는 이 파일을 먼저 고친다.

각 항목의 글자 수 제한이 다르고 한글도 한 글자로 센다. 아래 숫자는 현재 길이다.
언어는 한국어 하나만 둔다.

---

## 앱 이름 (3 / 30자)

```
가계력
```

---

## 부제 (10 / 30자)

> 집중력의 "나만의 집중 타이머", 책력의 "나만의 독서 달력" 과 짝을 이룬다. 앱 이름은 이미 함께 표시되므로 넣지 않는다.

```
나만의 가계부 달력
```

---

## 프로모션 텍스트 (65 / 170자)

> 빌드를 새로 올리지 않고도 언제든 바꿀 수 있는 항목이다.
> 둘째 줄은 집중력·책력과 함께 쓰는 문장이다. 바꾸려면 두 앱 쪽도 같이 바꾼다.

```
쓴 돈을 적으면 날짜 칸에 놓입니다. 한 달을 넘겨 보면 돈의 흐름이 바로 보입니다.
하루하루가 쌓여 기록이 됩니다.
```

---

## 키워드 (73 / 100자)

> 쉼표 뒤에 공백을 넣지 않는다 — 공백도 글자 수에 들어간다.
> 앱 이름과 부제에 있는 낱말(가계력, 나만의, 가계부, 달력)은 이미 색인되므로 단독으로 넣지 않는다.

```
지출,수입,용돈기입장,자동이체,구독,구독관리,고정지출,돈관리,생활비,잔액,계좌,통장,절약,소비,소비기록,지출관리,캘린더,통계,기록장
```

---

## 설명 (744 / 4000자)

> 첫 세 줄만 접히지 않고 보인다. 거기서 이 앱이 무엇인지 끝나야 한다.
> 마지막 줄은 프로모션 텍스트 둘째 줄과 같은, 집중력·책력과 함께 쓰는 문장이다.
> 예산, CSV 가져오기, 추이 그래프는 기획서에는 있지만 아직 없는 기능이라 쓰지 않는다.
> "어디로도 전송되지 않습니다" 는 앱에 네트워크 통신이 없어서 쓸 수 있다. 서버 동기화를 붙이면 고친다.

```
가계력은 쓴 돈을 달력에 기록하는 가계부 앱입니다.

날짜 칸마다 수입과 지출이 놓입니다. 한 달을 넘겨 보면 돈의 흐름이 바로 보입니다.


■ 달력으로 한눈에

날짜마다 수입은 파랑, 지출은 빨강으로 표시됩니다.
화면 위에서 이번 달 수입, 지출, 합계를 보고, 날짜를 누르면 그날 내역이 열립니다.


■ 금액부터 바로

입력 화면을 열면 금액부터 적습니다.
최근 사용한 카테고리와 계좌가 앞에 놓여 있어 몇 번만 누르면 끝납니다.


■ 지출, 수입, 이체

계좌 사이에 옮긴 돈은 이체로 기록합니다.
지출로 세지 않으므로 생활비 통장에 돈을 옮겨도 합계가 부풀지 않습니다.


■ 자동이체

구독료와 고정 지출을 매월 또는 매년 주기로 등록합니다.
출금일이 지나면 거래로 기록되고, 앞으로 빠져나갈 금액은 달력에 미리 표시됩니다.


■ 계좌별 잔액

계좌마다 현재 잔액을 봅니다. 생활비처럼 용도를 적어 둘 수 있고,
계좌를 누르면 그 계좌의 내역이 열립니다.


■ 내역과 통계

내역은 달별로 모아 유형, 계좌, 카테고리로 걸러 봅니다.
통계에서는 그달의 수입, 지출, 순액과 카테고리별 지출 비율을 봅니다.


■ 기록은 이 기기 안에

가계부 기록은 이 기기 안에만 저장되며 어디로도 전송되지 않습니다.
앱을 지우면 함께 사라지지만, 파일 하나로 백업해 두면 새 iPhone 에서 그대로 복원할 수 있습니다.


은행이나 카드사를 연결하지 않습니다. 직접 적은 만큼만 기록됩니다.
하루하루가 쌓여 기록이 됩니다.
```

## 심사 메모

> 심사 중에 막힐 만한 것을 미리 적어 둔다. 계정이 없고, 금융 카테고리라 은행 연동 여부를 분명히 한다.

```
로그인이나 계정 없이 바로 사용할 수 있습니다.

앱은 서버가 없으며 가계부 기록은 기기 안에만 저장합니다. 네트워크 통신을 하지 않고,
은행이나 카드사 계정에 연결하지 않습니다.

백업은 사용자가 직접 실행할 때만 파일을 만들어 iOS 공유 시트로 넘기고, 복원은 사용자가
파일 앱에서 고른 파일을 읽습니다.
```
